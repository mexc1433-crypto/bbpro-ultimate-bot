# BBPro Ultimate - Bollinger Breakout Pro

Professional automated trading bot for cTrader using Python.

## Features
- Bollinger Bands Breakout Strategy
- RSI + EMA + ADX + ATR filters
- Multi-symbol: EURUSD, XAUUSD, GBPUSD, USDJPY
- Telegram notifications
- Web dashboard (port 5100)
- Stochastic, MACD, Williams %R, CCI, Pivot Points, Fibonacci, Heikin Ashi

## Environment Variables
- `CTRADER_CLIENT_ID_3` - cTrader App Client ID
- `CTRADER_SECRET_4` - cTrader App Secret
- `CTRADER_ACCESS_TOKEN_2` - cTrader Access Token
- `TELEGRAM_BOT_TOKEN` - Telegram Bot Token
- `TELEGRAM_CHAT_ID` - Telegram Chat ID (7005859703)
